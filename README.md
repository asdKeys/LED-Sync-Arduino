# [ARDUINO]LED Sync

## About

3 LED's blinking in order.

## How to Use

First, download the Arduino IDE if you don't have it. Then, go to the file called "Triple_Blink_LED.ino" and copy and paste that into the Arduino IDE. The wiring is listed below with a diagram.

## Building

### Parts Needed

- Any Arduino board.
- A breadboard.
- A button
- 3 LED's (any color).
- 3 220 ohm resistors.
- 7 wires.
